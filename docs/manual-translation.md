# 论文精读翻译

## 这条路线解决什么

paper-lens 应用内有两个自动解析引擎：本地几何规则、整页视觉模型。两者都在猜版面，
上限有限。而我读 PDF 时是**整页看**的——和人一样，不需要判断"这块是正文还是插图"，
直接在理解内容。所以碰到下面这些情况，直接由我来读、来译，效果远好于任何自动流程：

- 公式密集的论文（自动流程会把公式截成图，或还原成 `∂w⋆/∂rˆ` 这种乱码）
- **PDF 文本层本身损坏**：`∂` 存成 `@`、`≠` 存成 `6=`、希腊字母直接丢失
- 双栏、多栏、图文混排
- 读者要的是"读得懂"，不是"跑得快"

代价是慢，而且要占我的上下文。一篇 40 页的论文大约要分 4–6 轮读完。

## 工作流

### 1. 勘察

```bash
python3 tools/survey.py <pdf>
```

输出每页的文本块数、矢量绘图数、位图数，据此判断哪几页有真插图。只有那几页需要
`@fig`，其余页面纯文字＋公式。

### 2. 读原文

用 Read 工具带 `pages` 参数读 PDF，**每次不超过 8 页**（再多会稀释注意力，公式容易抄错）。
读完一批就立刻写这一批的稿子，不要攒着。

### 3. 写稿

稿子是纯文本，格式见下。写的时候守三条：

1. **公式照抄成 LaTeX，不要意译**。行内 `\( ... \)`，行间用 `@math` 块。
   编号用 `\tag{1}`。抄完回头对一眼原图，下标和撇号最容易错。
2. **译文只用逗号句号**，不用设问、不用空转折、不用修辞收尾；承接靠事实
   callback，不靠连接词。用词干练。
3. **一个块对应原文一个自然段**。不要合并，不要拆开——块是标注和翻译缓存的单位。

### 4. 编译

```bash
python3 tools/build.py <pdf> <稿子.txt> <输出.json>
```

工具按 `@fig` 给的坐标从 PDF 里裁图（200dpi，WebP），内嵌成 dataURL，打包成一个 json。

### 5. 导入

在 paper-lens 首页点「导入已翻译文档（.json）」。导入后所有功能照常：中英对照、
划词标注、点公式问 AI、深色模式。

## 稿子格式

```
@meta
title-en: Selection of Estimation Window in the Presence of Breaks
title-zh: 存在结构断点时估计窗口的选择
file: estimation-window.pdf

@page 2                         之后的块都算第 2 页（影响页码角标和插图裁剪）

@h1 / @h2 / @h3                 标题，h1 用作全文标题
@p                              正文段落
@note                           脚注、作者信息、关键词这类小字
@cap                            图题表题
@math                           行间公式，只写 LaTeX，不译
@ref                            参考文献条目，不译
@fig x0,y0,x1,y1                按 PDF 坐标（pt，左上origin）从当前页裁图
```

块内用单独一行 `--` 分隔原文与译文。没有 `--` 的块只有原文（`@math` `@ref` 用这种）。
空行结束一个块。

例：

```
@p
Here \(\mathbf{1}_{\{t \leq T_1\}}\) is an indicator variable that takes the value of one.
--
其中 \(\mathbf{1}_{\{t \leq T_1\}}\) 是示性变量，取值为 1。

@math
\[ y_{t+1} = \boldsymbol{\beta}_1'\mathbf{x}_t + u_{t+1} \tag{1} \]
```

## 怎么定 `@fig` 的坐标

先看 `survey.py` 指出哪页有图，再读那一页的图像，按版面估坐标（页面通常是
612×792pt，左上角为原点）。拿不准就宁可框大一点——多留白不影响阅读，切掉半张图很难看。
裁完务必回看一眼 `build.py` 的输出尺寸是否合理。

## 注意

- **公式对不对，只能靠回看原图核对。** 这是整条流程里唯一没有自动校验的环节。
- 参考文献用 `@ref`，不要翻译。整页文献条目翻出来既费事又没人看。
- 页眉页脚、孤立页码不要写进稿子。
- 稿子可以分批写、追加到同一个文件，最后一次性编译。
